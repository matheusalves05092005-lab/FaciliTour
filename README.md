# FaciliTour
Plataforma inteligente de turismo focada em experiências personalizadas, roteiros e praticidade para viajantes.
# Objetivo
Desenvolver uma solução moderna e intuitiva para conectar turistas a experiências, locais e serviços de maneira simples e eficiente.

# Funcionalidades
- Roteiros personalizados
- Exploração de pontos turísticos
- Sistema de avaliações
- Interface intuitiva
- Integração com mapas
- Recomendações inteligentes

# Tecnologias
- Figma
- HTML/CSS
- JavaScript
- React
- Node.js
